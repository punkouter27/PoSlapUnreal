Menu screen rework

2026-11-09. User request: show the main menu first without the scene, keep the two apart, and make the layout more professional with all 16 places and byes visible.

After

What changed

  • The menu is its own screen. An opaque backdrop covers the whole viewport and the panel fills the space between the top and bottom anchor rows, so the arena is never seen behind it.
  • No match overlays (scoreboard, plates, captions, live telemetry) are drawn while the menu is open.
  • A league header shows how the 16 places are filled. The lit tab has a gold underline. START is wider and sits at the bottom centre.
  • The 16-place grid labels each open place "BYE", matching how the bracket fills it.
  • The menu closes with X, the menu icon or START. Tapping outside no longer closes it, because there is no outside any more.
