HUD: last turn's strike no longer carries over (2026-10-23)

Before: when a turn started, the HUD cleared only the "struck" flag. The previous striker's "Hand speed" and "Head snap" lines (shown whenever the speed is above zero) and the previous call ("Foul: clubbing", "Foul: out of the box") stayed on screen for the whole of the opponent's turn, so it read as if the new striker had already hit. After: each turn starts with the speed, head snap, hit part and call cleared; the coin-toss message is still shown at the start of a match. The last turn's result stays on screen during the 2 s pause between turns, as before.
