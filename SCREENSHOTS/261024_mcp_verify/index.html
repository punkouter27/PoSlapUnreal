7. Working MCP recipe (for reuse)

UE 5.8 uses Streamable HTTP, not plain POST:

  • GET /mcp returns 405 — that is spec-compliant, not a fault.
  • POST responses arrive as SSE frames (data: {...}); the server holds the connection ~30 s, so a short client timeout looks like a failure even after the request was processed (check LogModelContextProtocol).
  • Send Accept: application/json, text/event-stream and echo the Mcp-Session-Id header on every later call.
  • Always post {"jsonrpc":"2.0","id":N,"method":...}; call inner tools through call_tool with toolset_name / tool_name / arguments, where tool_name is the short name (SetVerbosity, not EditorToolset.LogsToolset.SetVerbosity).
  • Images come back as returnValue.data (editor image) or returnValue.image.data (viewport).
